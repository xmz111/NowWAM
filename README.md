# NowWAM

**Beyond Future Prediction: Denoising as Generative Adaptation for Robot Control**

NowWAM adapts pretrained generative models to robot control through current-observation denoising, without a separate future-target branch.

[[Project page](https://xmz111.github.io/NowWAM/)] [[Paper](https://arxiv.org/abs/2609.28339)]

Zanyi Wang, Yuheng Lei, Dengyang Jiang, Ping Luo, Mengdi Wang, Zhixuan Liang, and Shilong Liu
